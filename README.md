The Creator: HTML was created by Sir Tim Berners-Lee while he was working at CERN, the European Organization for Nuclear Research.
The Motivation: Berners-Lee wanted to create a system that allowed researchers to share documents and link them together easily across different computers using the internet. He also invented URI (Uniform Resource Identifier) and HTTP (Hypertext Transfer Protocol) around the same time.
First Mention: The first publicly available description of HTML was a document called "HTML Tags" published on the early internet by Berners-Lee in late 1991. It described just 18 elements—many of which were inspired by SGML (Standard Generalized Markup Language).
